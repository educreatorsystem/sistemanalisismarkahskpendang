# Sistem Analisis Peperiksaan — SEKOLAH KEBANGSAAN PENDANG

Sistem ini menggunakan nama dan lencana SK Pendang serta pautan baharu Google Sheets / Apps Script.

## GitHub Pages
1. Muat naik fail `index.html` ke repository GitHub.
2. Pergi ke Settings > Pages.
3. Pilih Deploy from a branch, branch main, folder / (root).
4. Terbitkan.

## Google Sites
Cara yang disyorkan: terbitkan sistem di GitHub Pages, kemudian gunakan **Insert > Embed > By URL** di Google Sites dan tampal URL GitHub Pages.

Alternatif: gunakan kod lengkap HTML dalam `kod_html_google_sites_sk_pendang.txt` untuk **Insert > Embed > Embed code**. Sesetengah skrip mungkin dihadkan dalam persekitaran Google Sites.

Nota: Kebenaran Apps Script (Web App) dan penerbitan CSV perlu ditetapkan dengan betul. Semak sambungan sebenar selepas terbitkan.
